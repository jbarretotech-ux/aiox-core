## Visual
- Um plano só, sem cortes secos: tudo é texto e interface se transformando.
- Fundo quase preto com brilho laranja suave no centro e grade bem fraca.
- Fonte grotesca bem grossa (branco) + destaque laranja em caixinha ("agora", "não", "IA") + itálico serifado nas palavras de ênfase ("normal", "escrito", "relaxa", "conversa").
- Riscado vermelho nas negações (EDITADO, After Effects, Premiere, timeline).
- Cursor com etiqueta laranja "Claude" é o "editor": clica, arrasta, digita.
- Cada frase vira uma imagem literal: pasta PENDRIVE_DO_PRIMO indo pro lixo, timeline com keyframes, janela "Abrir software gráfico? Cancelar", curva de keyframe com proibido, barra de render 26% → 98% → "99%" com glitch, editor de código digitando html, navegador "Feito em HTML", filme "frame 0001/2562", celular "video.mp4", texto dentro do celular dentro do celular (meta), ícone de nó, onda "relaxa", forma de onda do áudio "gravando_esse_audio.wav", bolinhas de cor + chat "muda a cor pra", gráfico de barras acelerando "2x", palavra "trema" tremendo, timeline sendo apagada, chat "cria um motion pra esse áudio" → "Pronto! Tá aqui", caixa de comentário digitando MOTION + coração.
- Segunda metade ganha roxo/azul como segunda cor.
- Ritmo: imagem nova a cada 1–2 s; palavras entram junto com a fala; cartões com leve 3D, desfoque na entrada e saída, pops de escala.

## Por que funciona
1. Gancho que contradiz o que você vê ("não foi editado").
2. Mostrar, não contar: cada frase tem a sua imagem literal.
3. Humor local ("CapCut pirata do teu primo").
4. Virada meta que prende ("o texto falando dele mesmo").
5. CTA de palavra única ligado ao tema (MOTION).
